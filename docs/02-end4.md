# end-4 (illogical-impulse)

[end-4/dots-hyprland](https://github.com/end-4/dots-hyprland) — Hyprland +
Quickshell. Reemplazó a HyDE en las tres máquinas.

```bash
git clone https://github.com/end-4/dots-hyprland ~/dots-hyprland
cd ~/dots-hyprland && ./setup install
```

Instala ~15 metapaquetes `illogical-impulse-*`. **`uwsm` no está entre ellos** —
es dependencia *opcional* de Hyprland y hay que pedirla aparte:

```bash
paru -S uwsm
```

Sin uwsm, `graphical-session.target` no se activa y ningún servicio de usuario
arranca. En SDDM hay que elegir **«Hyprland (uwsm-managed)»**.

> Después de la instalación: `rm -rf ~/.cache/yay` — la compilación deja
> decenas de GB.

---

## El problema de fondo

end-4 son **dotfiles, no una distro**. Personalizar algo que no esté expuesto en
su app de ajustes significa editar archivos **dentro del proyecto**, y
`./setup install` los sobrescribe en cada actualización.

De los ajustes de estas máquinas, **todos** viven en archivos que el update pisa:

| Ajuste | Archivo | ¿Lo borra el update? |
|---|---|---|
| Notificaciones expandidas | `modules/common/widgets/NotificationGroup.qml` | sí |
| `SUPER+A` lanzador | `hypr/hyprland/keybinds.lua` | sí |
| Indicador de updates | `modules/ii/bar/BarContent.qml` | sí |
| Conteo con AUR | `services/Updates.qml` | sí |
| Colores de kitty | `scripts/colors/applycolor.sh` | sí |
| Límite del thumbnailer | `scripts/thumbnails/generate-thumbnails-magick.sh` | sí |

De ahí [`end4-post-install.sh`](../scripts/end4-post-install.sh): **idempotente**,
se corre después de cada `./setup install`.

```bash
KB_LAYOUT=latam ~/.local/bin/end4-post-install.sh
```

Lo que sí persiste son los archivos de `~/.config/hypr/custom/` — ahí van los
ajustes de teclado, touchpad y variables.

## Los 11 pasos

| # | Qué | Por qué |
|---|---|---|
| 1 | `HYPRLAND_CONFIG` | HyDE lo inyecta desde zsh **y** uwsm; sin override secuestra el arranque |
| 2 | `kb_layout` | end-4 trae `us` en un archivo suyo; se mueve a `custom/general.lua` |
| 3 | hypridle | *opcional* — desactiva bloqueo y suspensión por inactividad |
| 4 | `SUPER+H` chuleta | `SUPER+Slash` es inalcanzable en `es`/`latam`: la `/` requiere Shift |
| 5 | shell de kitty | end-4 impone `fish`. Se pone `shell .` = el de `/etc/passwd` |
| 6 | Notificaciones | popups abiertas en vez de colapsadas a una línea |
| 7 | `SUPER+A` | abre el lanzador; pulsar `SUPER` solo no viaja por VNC |
| 8 | Colores de kitty | paleta wallbash del wallpaper |
| 9 | Indicador de updates | la familia `ii` no lo trae; `waffle` sí |
| 10 | Conteo AUR | `checkupdates` ignora el AUR |
| 11 | Prompt | que mande el starship de end-4, no el de HyDE |

> **Paso 3, aviso:** desactivar hypridle quita también el bloqueo de pantalla. En
> equipos de escritorio permanente es lo deseado; en una laptop probablemente no.
> Y el listener de suspensión a los 15 min **rompe el acceso remoto**.

> **Paso 5, aviso:** `shell zsh` a pelo rompe kitty en una máquina donde zsh no
> esté instalado. `shell .` sigue al shell de login y se ajusta solo tras `chsh`.

## Colores de kitty

end-4 toma una base Gruvbox fija y la **rota hacia un solo acento**
(`harmonize()`), así que con cualquier wallpaper todo sale del mismo tono.

[`wallbash-kitty.sh`](../scripts/wallbash-kitty.sh) usa el extractor de HyDE:
k-means sobre el wallpaper → **4 colores dominantes** → los slots ANSI. Se
engancha al final de `applycolor.sh`, así que corre en cada cambio de wallpaper.

Detalles que costaron encontrar:

- **Se reduce la imagen a 512px antes del k-means.** Los colores dominantes son
  los mismos que a 4K, pero el coste en memoria baja órdenes de magnitud. Sin
  esto, un wallpaper 4K puede disparar el OOM killer.
- **Se fuerza modo oscuro (`-d`)** y se sube `txt1..txt4`. En modo «auto», con un
  wallpaper claro wallbash invierte la paleta y queda texto oscuro sobre fondo
  oscuro. Validado con WCAG en wallpapers claros y oscuros.
- **Se reescribe `sequences.txt`** con la misma paleta: end-4 lo emite a todas
  las `/dev/pts` después de que kitty cargue su config, y si no coinciden, pisa
  los colores en vivo.

Las copias del extractor se vendorizan en `~/.local/lib/wallbash/` para no
depender de que HyDE siga instalado.

## Ajustes que viven en `config.json`

`~/.config/illogical-impulse/config.json` **no lo toca** `./setup install`, pero
tampoco lo cubre el post-install:

```json
{
  "apps": {
    "update": "kitty zsh -ic 'yay -Syu; echo; echo \"── Update finished. Press Enter to close ──\"; read'"
  },
  "updates": { "checkInterval": 30 },
  "background": {
    "widgets": {
      "clock": { "enable": true, "showOnlyWhenLocked": true, "style": "digital", "styleLocked": "digital" }
    }
  }
}
```

- El `apps.update` de serie es `pkexec pacman -Syu` dentro de fish, y **no
  funciona**: `pkexec` no propaga la terminal a un comando interactivo. Además
  ignora el AUR.
- `checkInterval` por defecto son 120 min: el contador se queda obsoleto tanto
  tiempo que parece roto.
- El reloj del **lockscreen** y el del **escritorio** son el mismo widget y
  respetan `enable`. El del **login de SDDM** lo dibuja el tema y **no** lo
  respeta — por eso puede aparecer en uno y no en el otro.

## Atajos propios

```
SUPER + A                 lanzador (searchToggle)
SUPER + H                 chuleta de atajos
CTRL + SUPER + T          selector de wallpapers
CTRL + SUPER + ALT + T    wallpaper al azar
CTRL + ALT + Supr         menú de sesión
```

> Los binds de `custom/keybinds.lua` **solo se cargan al arrancar Hyprland**.
> `hyprctl reload` no los toma.
