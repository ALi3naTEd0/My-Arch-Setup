# end-4 (illogical-impulse)

[end-4/dots-hyprland](https://github.com/end-4/dots-hyprland) — Hyprland +
Quickshell. Replaced HyDE on all three machines.

```bash
git clone https://github.com/end-4/dots-hyprland ~/dots-hyprland
cd ~/dots-hyprland && ./setup install
```

It installs ~15 `illogical-impulse-*` metapackages. **`uwsm` is not among
them** — it is an *optional* dependency of Hyprland and has to be requested
separately:

```bash
paru -S uwsm
```

Without uwsm, `graphical-session.target` never activates and no user service
starts. In SDDM you must pick **"Hyprland (uwsm-managed)"**.

> After installing: `rm -rf ~/.cache/yay` — the build leaves tens of GB behind.

---

## The underlying problem

end-4 is **dotfiles, not a distro**. Customising anything not exposed in its
settings app means editing files **inside the project**, and `./setup install`
overwrites them on every update.

Of the tweaks on these machines, **all of them** live in files the update wipes:

| Tweak | File | Wiped by update? |
|---|---|---|
| Expanded notifications | `modules/common/widgets/NotificationGroup.qml` | yes |
| `SUPER+A` launcher | `hypr/hyprland/keybinds.lua` | yes |
| Updates indicator | `modules/ii/bar/BarContent.qml` | yes |
| AUR-aware count | `services/Updates.qml` | yes |
| kitty colors | `scripts/colors/applycolor.sh` | yes |
| Thumbnailer limit | `scripts/thumbnails/generate-thumbnails-magick.sh` | yes |

Hence [`end4-post-install.sh`](../scripts/end4-post-install.sh): **idempotent**,
run it after every `./setup install`.

```bash
KB_LAYOUT=latam ~/.local/bin/end4-post-install.sh
```

What does persist are the files under `~/.config/hypr/custom/` — keyboard,
touchpad and variables belong there.

## The 15 steps

| # | What | Why |
|---|---|---|
| 1 | `HYPRLAND_CONFIG` | HyDE injects it from both zsh **and** uwsm; without an override it hijacks startup |
| 2 | `kb_layout` | end-4 ships `us` in its own file; moved to `custom/general.lua` |
| 3 | hypridle | *optional* — disables idle lock and suspend |
| 4 | `SUPER+H` cheatsheet | `SUPER+Slash` is unreachable on `es`/`latam`: `/` needs Shift |
| 5 | kitty shell | end-4 forces `fish`. Set to `shell .` = the one in `/etc/passwd` |
| 6 | Notifications | popups open instead of collapsed to one line |
| 7 | `SUPER+A` | opens the launcher; tapping `SUPER` alone doesn't travel over VNC |
| 8 | kitty colors | wallbash palette from the wallpaper |
| 9 | Updates indicator | the `ii` panel family doesn't ship one; `waffle` does |
| 10 | AUR count | `checkupdates` ignores the AUR |
| 11 | Prompt | let end-4's starship win, not HyDE's |
| 12 | `.zshrc` | on machines without HyDE there is no zsh startup chain at all |
| 13 | Browser + `$BROWSER` | end-4 prioritises `google-chrome-stable` |
| 14 | `apps.update`, `checkInterval` | the stock update command does not work |
| 15 | **Thumbnailer limit** | **without it, the OOM crash returns** |

> **Step 3, warning:** disabling hypridle also removes the screen lock. Fine on
> an always-on desktop, probably not on a laptop. And the 15-minute suspend
> listener **breaks remote access**.

> **Step 5, warning:** a bare `shell zsh` breaks kitty on a machine where zsh
> isn't installed. `shell .` follows the login shell and adjusts itself after
> `chsh`.

## kitty colors

end-4 takes a fixed Gruvbox base and **rotates it toward a single accent**
(`harmonize()`), so with any wallpaper everything comes out the same hue.

[`wallbash-kitty.sh`](../scripts/wallbash-kitty.sh) reuses HyDE's extractor:
k-means over the wallpaper → **4 dominant colors** → the ANSI slots. It hooks
onto the end of `applycolor.sh`, so it runs on every wallpaper change.

Details that were expensive to find:

- **The image is downscaled to 512px before k-means.** The dominant colors are
  the same as at 4K, but memory cost drops by orders of magnitude. Without this,
  a 4K wallpaper can trigger the OOM killer.
- **Dark mode is forced (`-d`)** and `txt1..txt4` are lifted. In "auto" mode a
  light wallpaper makes wallbash invert the palette, leaving dark text on a dark
  background. Validated with WCAG on both light and dark wallpapers.
- **`sequences.txt` is rewritten** with the same palette: end-4 emits it to
  every `/dev/pts` after kitty loads its config, and if they disagree it
  overrides the live colors.

Copies of the extractor are vendored into `~/.local/lib/wallbash/` so nothing
depends on HyDE staying installed.

## Settings that live in `config.json`

`~/.config/illogical-impulse/config.json` is **not** touched by
`./setup install`, but step 14 handles it anyway:

```json
{
  "apps": {
    "update": "kitty zsh -ic 'yay -Syu; echo; echo \"── Update finished. Press Enter to close ──\"; read'"
  },
  "updates": { "checkInterval": 30 },
  "background": {
    "widgets": {
      "clock": { "enable": true, "showOnlyWhenLocked": true, "style": "digital", "styleLocked": "digital" }
    }
  }
}
```

- The stock `apps.update` is `pkexec pacman -Syu` inside fish and **does not
  work**: `pkexec` does not pass a terminal to an interactive command. It also
  ignores the AUR.
- `checkInterval` defaults to 120 min: the counter goes stale long enough to
  look broken.
- The **lockscreen** clock and the **desktop** clock are the same widget and
  both honour `enable`. The **SDDM login** clock is drawn by the theme and does
  **not** — which is why it can show up in one and not the other.

## Custom shortcuts

```
SUPER + A                 launcher (searchToggle)
SUPER + H                 shortcut cheatsheet
CTRL + SUPER + T          wallpaper selector
CTRL + SUPER + ALT + T    random wallpaper
CTRL + ALT + Del          session menu
```

> Binds in `custom/keybinds.lua` are **only loaded when Hyprland starts**.
> `hyprctl reload` does not pick them up.
